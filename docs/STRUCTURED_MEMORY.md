# 第二轮专项记忆优化

本轮基于660a08f，增加可落库、可追溯、可独立测试的专项机制。

| 失分项 | 本轮实现 | 边界 |
|---|---|---|
| D1/D2 当前状态与冲突 | 主体/属性/作用域/说话来源状态槽；按事件时间处理明确更新、更正、撤回；支持历史和as-of | 缺时间、同刻冲突、部分索引保留不确定性；提取及槽选择仍依赖模型 |
| F1 长历史综合 | 会话/主题两级提取式事实分页，每页最多16条，保留来源、原文位置、版本和反例 | 未生成自由文本全局结论；模型池30条、原文最多100条，超限记录不足 |
| G2 规则应用 | 对weight<=20、fragile=true等明确条件进行比较，匹配例外并保留全部必要规则 | 只执行直接声明的合取条件；unless、否定、析取及一般自然语言规则保持取证形式 |
| G4 经验规律 | 数值列数量/范围/均值/时间趋势、有理数精确仿射一致性；保留反例和缺失来源 | 不把样本拟合、外推、未来模拟当成已验证事实 |
| I1/I2 流式与迁移 | 一次Add提取同时生成结构化记录；更新受影响会话/主题分页；跨会话召回兼容观察模式 | 迁移提供已有案例依据，不伪造新对象事实；第一轮跨批上下文修复继续保留 |
| B2 因果链 | 原文直接陈述的causes/before/enables有向路径，最多3跳、每节点16条边，保留全部链路来源 | 不反转因果、不用相关性替代因果；用户内最多检查5000条边 |
| C2 事件顺序 | 显式before路径及反向顺序冲突检测、事件时间、历史/as-of路由 | 不是通用相对日期解析；as-of只接受查询中的明确ISO日期，按UTC该日结束 |
| H2 最小披露 | 完整标记的纯敏感消息，在未请求该字段时从成功选择及失败回退中排除 | 混有必要事实的原消息保持原文；未加入字段级改写，分类仍依赖提取器 |

## 来源、完整性与执行

`structured_records`保存精确原文起止位置；value、subject和显式scope须有原文见证。
相对日期不由提取器自行计算；显式生效日期也必须逐字出现。引述、假设、否定和未来
计划受到保守门控。这是有限语法防护，不是通用语义证明。

`structured_sources`记录来源提取完成标志：提取器声明完成且注释通过原文校验。
它不表示人工证明原文所有事实都已识别。旧数据库或开关混用造成的未索引消息会令
目录标记为部分索引；状态模块不据此屏蔽旧值。不自动调用模型回填老数据库。

`structured_rollups`保留每页的全部记录ID、原文ID和位置，按受影响的会话/主题重建
提取式事实页。正式对比宜用独立新库，通过正常Add重放输入。

规划器在原有一次调用中读取目录，最多128个组、128个主题，优先查询相关槽位。
专项模块形成必须保留的来源组。选择仍只调用一次，程序拒绝遗漏必需来源、使用
已确定过期值或虚报池内完整的决策。完整专项组可优先占用30条模型池，覆盖第一轮
普通候选保留比例，避免必要链路被普通候选挤掉。超限明确记录覆盖不足。

失败回退采用专项来源优先的原文结果，排除已过期及未请求的纯敏感来源，遵守top_k。
内部统计/路径仅是检索提示，API仍返回原消息。格式错误/截断保留原文和不完整标志，
不增加模型重试；供应商认证/连接异常继续暴露。诊断仅保存ID、数量、状态，
不保存查询、原文、敏感值和数值统计详情。

## 启用和回退

根目录`.env.text-optimized.example`已包含本轮配置，需通过进程环境加载：

```bash
MEMORY_STRUCTURED_QUERY_PLAN=true
MEMORY_EVIDENCE_SELECTION=true
MEMORY_COVERAGE_RETRIEVAL=true
MEMORY_STRUCTURED_MEMORY=true
```

密钥及数据库路径使用服务端实际值，保留MEMORY_REQUIRE_MODEL=true。
不与graph/anchors/SF组合，不增加依赖。每条消息一次提取，每次Search一次规划加一次
选择；token费用及延迟需要实测。本轮没有运行付费评测或更换服务器。

只回退本轮：structured开关设false。回退全部选择：selection/coverage/structured
三个开关同时设false并重启。新索引表可保留，原消息内容和ID不变。

## 验证

```powershell
& ../chrono-hybrid-mem-coding/.venv/Scripts/python.exe scripts/test_offline.py -q tests/test_structured_memory.py
```

用例覆盖乱序写入、同刻冲突、撤回、原文范围、引述截断、作用域和说话来源、部分旧库、
隐私回退、跨会话取证、规则例外、非有限数值/反例、路径方向/顺序冲突及目录/候选池限额。
模型输出均为独立合成夹具，验证程序机制，不代表真实模型理解能力或平台分数。
